# AI Support Ticket Frontend

Vite + React frontend for the AI Support Ticket Classification System.

Quick start:

```bash
cd frontend
npm install
npm run dev
```

Environment:

- Create `.env` with `VITE_API_URL=http://localhost:8000` if backend runs locally.

This scaffold includes Material UI, Tailwind, Framer Motion, Recharts, Axios, React Hook Form and React Hot Toast.
